# Shiraz Metro — Android Releases

> مخزن عمومی **صرفاً برای انتشار نسخه‌های اپلیکیشن غیررسمی راهنمای مترو شیراز** است. این مخزن سورس برنامه یا اطلاعات محرمانه ندارد و وابسته به اپراتور رسمی مترو شیراز نیست.

## وضعیت انتشار

**هنوز نسخه عمومی تأییدشده‌ای منتشر نشده است.** تا تکمیل آزمون گوشی، تأیید داده‌های ایستگاه‌ها و تنظیم امضای پایدار، هیچ APK آزمایشی را به‌عنوان نسخه رسمی دریافت نکنید.

وقتی نخستین نسخه منتشر شود:

- فایل `shiraz-metro-X.Y.Z-signed.apk` در قسمت [Releases](https://github.com/j1454am-lab/shiraz-metro-releases/releases) در دسترس خواهد بود.
- فایل `SHA256SUMS.txt` برای کنترل یکپارچگی همان APK ارائه می‌شود.
- فایل `latest.json` در ریشه این مخزن، **فقط بعد از انتشار موفق نسخه امضاشده**، نسخه جدید، لینک APK و SHA-256 واقعی را اعلام می‌کند.
- برنامه هنگام شروع، نسخه جدید را بررسی می‌کند و در صورت وجود بروزرسانی معتبر، گزینه‌های «بروزرسانی» و «بعداً» را نشان می‌دهد. نصب نهایی به تأیید کاربر نیاز دارد.

## تفکیک امنیتی

سورس و گردش‌کار ساخت در مخزن خصوصی جداگانه `j1454am-lab/shiraz-metro` نگهداری می‌شوند. کلیدهای امضا، رمزهای عبور و توکن‌های GitHub **نباید** در این مخزن، فایل `latest.json` یا Release assets درج شوند.

APK برای نصب روی نسخه فعلی گوشی باید شناسه بسته و گواهی امضای سازگار داشته باشد؛ Debug buildها قابل ارتقا به انتشار رسمی نیستند.

**Distribution status:** Pending first signed, device-tested public release. No VPS is required; GitHub Releases hosts signed APKs and public release metadata.
